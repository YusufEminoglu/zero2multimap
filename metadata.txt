about=02Multimap is an advanced, high-performance workspace plugin designed for comparative spatial analysis and multi-scenario map visualization. Ideal for urban planners, environmental researchers, and demographers, it allows you to compare multiple spatial patterns side-by-side in a coordinated layout. Online User Manual & Documentation: https://geophilo.com/zero2multimap/ | If you find this plugin helpful, please consider starring the repository on GitLab (https://gitlab.com/geophilo1/zero2multimap)!
    
    Key Capabilities:
    1. Synchronized Viewport Grids: Rebuild your workspace into 2, 3, 4, 6, or 8 synchronized map canvases (in horizontal, vertical, or grid matrices).
    2. Clean Active Panel Framing: Active viewport is highlighted strictly by its frame border without tinting or obscuring non-active comparison panels.
    3. Multi-Panel Feature Inspector: Query vector attributes and raster cell values at any coordinate point across all active viewports simultaneously.
    4. Visual Spatial Difference Engine: Compute geometric differences between comparison layers with green (added) and red (removed) overlays.
    5. Viewport Spatial KPIs & Area Chips: Calculate real-time polygon areas (ha/km²) and feature counts beneath each panel card. Areas are measured on the ellipsoid, so the readout is the same true ground area whether the layer is stored in a geographic CRS, in Web Mercator, or in a local projected CRS.
    6. Workspace Presets & Templates: Save and restore custom comparison layouts or use built-in scenario templates (Before & After, 4-Scenario Matrix, Temporal Timeline).
    7. Unified Legend Drawer & Canvas HUD: Access a right-side drawer stacking all panel legends and overlay North arrow / scale graphics on canvas corners.
    8. Synchronized Measurement Tool: Measure distance and area interactively across viewports in QGIS and exported HTML dashboards.
    9. Professional Print Layouts & Multi-Theme HTML Dashboards: Export exact panel rendering to print layouts (PDF, PNG, JPG, SVG) and self-contained HTML files featuring North Arrows, dynamic ground Scale Bars, multi-layer and per-panel Legends across 2 to 8 panels, Slate Light, Dark Midnight, and Emerald Clean themes, presentation slide mode, opacity controls, and measurement tools.
