about=02Multimap is an advanced, high-performance workspace plugin designed for comparative spatial analysis and multi-scenario map visualization. Ideal for urban planners, environmental researchers, and demographers, it allows you to compare multiple spatial patterns side-by-side in a coordinated layout. Online User Manual & Documentation: https://yusufeminoglu.github.io/zero2multimap/ | If you find this plugin helpful, please consider starring the repository on GitHub (https://github.com/YusufEminoglu/zero2multimap)!
    
    Key Capabilities:
    1. Synchronized Viewport Grids: Rebuild your workspace into 2, 3, 4, 6, or 8 synchronized map canvases (in horizontal, vertical, or grid matrices).
    2. Dynamic Extent Bounding Box: Overlay the active viewport rectangle over all other viewports to visualize geographic context immediately.
    3. Quick Panel Controls & Micro-Legends: Zoom to layer extent, adjust transparency sliders, toggle floating mini-legends, view geometry badges, and save PNG snapshots.
    4. Synchronized Measurement Tool: Measure distance and area interactively across viewports in QGIS and exported HTML dashboards.
    5. Time-Series Auto-Fill: Automatically sort layers chronologically by date/year and assign across comparison viewports.
    6. Bi-directional Navigation & Cartographic Scale Presets: Coordinate map navigation across all panels and jump instantly to standard cartographic scales.
    7. Synchronized Laser Cursor: Track coordinates across all canvases simultaneously with custom colored crosshairs following your mouse movement.
    8. Professional Print Layouts: Add titles, 5 Scalebar options, and 5 North Arrow graphics, exporting the grid matrix directly to PDF, SVG, PNG, or JPEG.
    9. Premium HTML Dashboards: Export exact panel rendering to self-contained HTML files featuring Slate Light, Dark Midnight, and Emerald Clean themes with live theme switching, opacity controls, measurement tool, and legends.
    10. Smart Auto-Fill: Choose a grid size and automatically assign a different layer to every panel, prioritizing layers that intersect the current QGIS map extent.
